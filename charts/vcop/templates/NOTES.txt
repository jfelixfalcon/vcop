Thank you for installing {{ .Chart.Name }}!

vCluster Center of Operations (vCOp) v{{ .Chart.AppVersion }} successfully deployed!
========================================================================

1. Check Operator Status:
  kubectl get pods -n {{ .Release.Namespace }} -l app.kubernetes.io/name={{ include "vcop.name" . }}-operator

2. Check Operations Center UI Status:
  kubectl get pods -n {{ .Release.Namespace }} -l app.kubernetes.io/name={{ include "vcop.name" . }}-ui

3. Access the Operations Center Dashboard:
{{- if .Values.ui.ingress.enabled }}
  URL: http://{{ (index .Values.ui.ingress.hosts 0).host }}
{{- else if eq .Values.ui.service.type "NodePort" }}
  export NODE_PORT=$(kubectl get --namespace {{ .Release.Namespace }} -o jsonpath="{.spec.ports[0].nodePort}" services {{ include "vcop.fullname" . }}-ui)
  export NODE_IP=$(kubectl get nodes --namespace {{ .Release.Namespace }} -o jsonpath="{.items[0].status.addresses[0].address}")
  echo http://$NODE_IP:$NODE_PORT
{{- else }}
  Run port forwarding to access the dashboard locally:
  kubectl port-forward -n {{ .Release.Namespace }} svc/{{ include "vcop.fullname" . }}-ui 4321:80

  Then open your browser at:
  http://localhost:4321
{{- end }}

4. Try provisioning your first VirtualCluster:
  kubectl apply -f https://raw.githubusercontent.com/vops/vc-operator/main/deploy/samples/dev_cluster.yaml
  kubectl get virtualclusters -A
